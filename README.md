# 29Ekim2013

Basit bir terminal tahmin oyunu. Bilgisayar 1 ile 100 arasında bir sayı tutar, sen de doğru sayıyı tahmin etmeye çalışırsın.

## Nasıl çalıştırılır?

1. Python 3 kurulu olduğundan emin ol.
2. Terminalde depo klasörüne gel ve aşağıdaki komutu çalıştır:

```bash
python3 game.py
```

## Oynanış

- Her turda bir tahmin girersin; `q` tuşu oyunu bırakır.
- Program, tahminin gizli sayıdan yüksek mi düşük mü olduğunu söyler.
- Doğru sayıyı bulduğunda kaç denemede başardığını gösterir ve istersen yeni bir tura geçebilirsin.
